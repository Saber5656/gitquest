# Title

Commit history stream reader: numstat parsing, incremental ranges, rewrite recovery

## Summary

Stream and parse `git log --numstat` output into typed commit records, supporting
full-history (first scan) and incremental (`last..HEAD`) ranges, plus the
history-rewrite fallback and the rename map via `diff-tree`.

## Context

This feeds the XP engine (15), the last-touched cache (11), and reconciliation
(26). DESIGN §5.2 fixes the exact command; §5.4 the rewrite rule.

## Scope

`internal/gitio/history.go` (+ tests):

```go
type Commit struct {
    SHA        string
    Parents    []string
    AuthorName string // for future use; hashed before persistence
    AuthorMail string
    When       int64  // author time (unix)
    IsMerge    bool
    Files      []FileChange // per-path insertions/deletions; binary = -1/-1
}
type FileChange struct{ Path string; Insertions, Deletions int; Binary bool }

// Walk streams commits oldest→newest, calling fn; stops on fn error.
func WalkHistory(ctx context.Context, r *Runner, rangeSpec string, fn func(Commit) error) error
// Reachable reports whether sha is an ancestor of HEAD (for rewrite detection).
func Reachable(ctx context.Context, r *Runner, sha string) (bool, error)
// RenameMap returns old→new path pairs between two commits (diff-tree -M50).
func RenameMap(ctx context.Context, r *Runner, fromSHA, toSHA string) (map[string]string, error)
```

## Detailed Requirements

1. Command (verbatim from DESIGN §5.2):
   `log --first-parent --reverse --date=unix -z --numstat --format=%x01%H%x00%P%x00%at%x00%aN%x00%aE`
   plus the range (`HEAD` or `<last>..HEAD`). Parser treats `\x01` as
   record start, `\x00` as field separator within the header, then numstat
   entries. Write the parser against captured real-git byte fixtures (commit at
   least 3 fixture files in `testdata/`, generated by a helper script and
   checked in) — NOT against hand-typed strings, because `-z` numstat framing
   is subtle (rename-less add/delete lines, binary `-` markers, path unquoting).
2. `IsMerge` = len(Parents) > 1. For merges, `Files` MUST be treated as
   unreliable by callers; reader still parses what git emits under
   `--first-parent` (diff vs first parent), which is exactly what XP/touched
   tracking wants.
3. Paths: `-z` disables quoting; paths are raw bytes → validate UTF-8; invalid
   or `..`-containing or absolute paths are skipped with a `ParseWarning`
   accumulated on the walk (DESIGN §10.2 treats them as hostile).
4. `Reachable` must use allowlisted subcommands only (`merge-base` is
   deliberately NOT in the runner allowlist). Algorithm:
   (a) `git rev-parse --verify --quiet <sha>^{commit}` — failure ⇒ return
   `(false, nil)` (unknown SHA is "not reachable", not an error);
   (b) `git rev-list --max-count=1 HEAD..<sha>` — EMPTY output ⇒ `<sha>` is an
   ancestor of (or equal to) HEAD ⇒ `(true, nil)`; non-empty ⇒ `(false, nil)`.
   Add a code comment explaining the `HEAD..<sha>`-emptiness ⇔ ancestor
   equivalence, and cover all branches with tests (ancestor, non-ancestor,
   unknown SHA).
5. `RenameMap`: `diff-tree -r -z -M50 --name-status --diff-filter=R <from> <to>`;
   parse `R<score>\0old\0new\0` records only.
6. Streaming: constant memory w.r.t. history size (no slurping); commits are
   delivered via callback; internal buffer ≤ 1 MiB.
7. Context cancellation kills the subprocess (verify no goroutine leak with
   `goleak` in tests or manual leak check).

## Acceptance Criteria

- [ ] Byte-fixture tests cover: normal commit, merge commit, binary file change,
      file with spaces/UTF-8 in path, rename-in-history (add+delete form),
      empty commit (no numstat block).
- [ ] Hostile-path fixture (`../evil`, absolute path injected into a crafted
      fixture) → skipped + warning, walk continues.
- [ ] Incremental walk over a fixture repo (`git` in temp dir): full walk sees
      N commits; after 2 new commits, `last..HEAD` walk sees exactly 2.
- [ ] `Reachable` truth table test passes (ancestor / descendant / unrelated / garbage SHA).
- [ ] `RenameMap` detects `git mv a.go b/c.go` with score ≥ 50.
- [ ] Race + leak clean.
